# Reflection

Working on the BrewMetrics BI project changed the way I approached the Power BI development process. Instead of creating the complete dashboard and saving it as one final file, I developed the solution in smaller stages and recorded each stage using Git commits.

AI assistance was useful when developing the DAX measures because it provided starting points for calculations such as month-over-month growth, running totals and RANKX-based ranking. However, the formulas still needed to be checked against the actual Power BI model. I had to verify table names, column names and the date context before accepting the results.

One important lesson was that AI-generated formulas should not be accepted without testing. The results need to be checked using the actual dataset.

GitHub also changed my workflow. Each important stage was committed separately, including the star schema, individual DAX measures and the dashboard. This created a clear history showing how the project developed.

Overall, the project helped me understand that AI can speed up development, but the final solution still requires human checking, testing and explanation. Version control also made the BI development process more organized and easier to review.
